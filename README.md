# Price Tracker

Телеграмм бот для проверки актуальной стоимости комплектующих для компьютера в известных магазинах. 

## Стек

Python 3.13, FastAPI, uv

## Запуск
```bash
команда установки зависимостей - uv sync
команда копирования .env.example в .env - Copy-Item .env.example .env
команда запуска - uv run price-tracker
```

После запуска: http://127.0.0.1:8000/health, документация API — /docs
## Разработка


```bash
команды линтера, проверки типов, тестов
```
